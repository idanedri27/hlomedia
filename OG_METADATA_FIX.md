# Open Graph Metadata Fix - HloMedia Public Website

## Problem Summary

Secondary pages (blog articles, static pages) reference `assets/images/og.jpg` which is:
- **Actual dimensions:** 452x902px (portrait)
- **Declared dimensions:** 1200x630px (landscape)
- **Issue:** Incorrect aspect ratio for Open Graph sharing

Home pages (`index.php` and `en.php`) work correctly but don't explicitly set language-specific images.

## Solution Implemented

### 1. Updated `includes/site-config.php`
Added language-specific OG image configuration:
```php
'og_image_he' => 'https://www.hlo-media.com/assets/hl/og-he.jpg',
'og_image_en' => 'https://www.hlo-media.com/assets/hl/og-en.jpg',
```

### 2. Updated `includes/head-meta.php`
Implemented language-aware OG image selection logic:
- If page explicitly sets `og_image` → use that
- Else if language is 'en' and `og_image_en` exists → use English image
- Else if language is 'he' and `og_image_he` exists → use Hebrew image
- Else → fallback to `default_og_image`

## Pages Affected

### ✅ Fixed (use centralized head-meta.php)
- `index.php` (Hebrew home)
- `en.php` (English home)

### ⚠️ Blog Articles (auto-generated, hardcoded metadata)
Blog articles (150+ files like `blog/article-*.php`) have hardcoded OG metadata:
```php
<meta property="og:image" content="https://www.hlo-media.com/assets/images/og.jpg">
```

**Note:** These are auto-generated by an external SEO agent system. Once the correct images are in place at `assets/hl/og-he.jpg` and `assets/hl/og-en.jpg`, you have two options:

1. **Recommended:** Update the blog article generation template in the SEO agent system to use the centralized approach
2. **Alternative:** Regenerate existing articles with updated template

- Twitter Card parity with Open Graph

### PHP Logic Details
The language-aware selection uses a priority cascade:
1. Explicit page override (`$page_meta['og_image']`)
2. Language-specific image (`og_image_en` or `og_image_he`)
3. Default fallback (`default_og_image`)

This ensures:
- Page-specific customization always works
- Language detection is automatic
- Graceful degradation if images missing
