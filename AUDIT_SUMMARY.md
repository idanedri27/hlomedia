### ⚠️ Issue Found: Default OG Image

**Problem:**
```php
// includes/site-config.php (before)
'default_og_image' => 'https://www.hlo-media.com/assets/images/og.jpg'
```

**Image analysis:**
```bash
$ identify assets/images/og.jpg
JPEG image data, 452x902, baseline, precision 8
```

**Declared dimensions in head-meta.php:**
```php
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
```

**Issue:** Portrait 452x902 image with declared landscape 1200x630 dimensions

**Impact:** Secondary pages using centralized metadata served incorrect aspect ratio for social sharing

## Solution Implemented

### 1. Configuration Enhancement
**File:** `includes/site-config.php`

Added language-specific image configuration:
```php
'og_image_he' => 'https://www.hlo-media.com/assets/hl/og-he.jpg',
'og_image_en' => 'https://www.hlo-media.com/assets/hl/og-en.jpg',
```

### 2. Smart Selection Logic
**File:** `includes/head-meta.php`

Implemented priority cascade:
```php
if (!empty($page_meta['og_image'])) {
    $og_image = $page_meta['og_image'];              // 1. Explicit override
} elseif ($lang === 'en' && !empty($cfg['og_image_en'])) {
    $og_image = $cfg['og_image_en'];                 // 2. English image
} elseif ($lang === 'he' && !empty($cfg['og_image_he'])) {
    $og_image = $cfg['og_image_he'];                 // 3. Hebrew image
} else {
    $og_image = $cfg['default_og_image'];            // 4. Fallback
}
```

### 3. Testing & Documentation
- `test-og-metadata.php`: PHP test script
- `OG_METADATA_FIX.md`: Integration guide
